# 项目、保存与命名版本（一次性原型）

最后更新：2026-09-21

本目录保留内存交互原型，用于比较布局与操作可读性；刷新即重置。原型未连接生产后端，其中的模拟数据、接口和保存流程不定义当前产品协议。生产行为以[项目工作区规格](../../../docs/2026-09-17-project-workspace-spec.md)及[WebUI 运行说明](../../../webui/README.md)为准。

## 界面方向

方案 A「上下文画布」：Workflow 保持主界面，项目身份、保存状态和版本来源持续可见，项目库按需打开。方案 B「版本时间线」和 C「实验项目库」用于布局比较。

## 运行

从仓库根目录运行：

```bash
.venv/bin/python .scratch/webui-product-definition/prototype-8-project-versioning/serve.py
```

打开 <http://127.0.0.1:4186/?variant=A>。使用 `?variant=A/B/C` 切换布局。

## 交互观察

观察项目切换、保存提示、命名版本、复制与恢复的对象身份表达，以及 Prompt 编辑区与项目保存提示的位置关系。

示例蛋白质、结构几何、参数、分数与来源标识只服务于交互演示。原型不能作为科学验收、持久化或生产接口测试的依据。
