# PROTOTYPE 5 — Blender 风格残基级结构编辑（一次性原型）

> 单文件逻辑原型。重写后不再比较 A/B/C 外观方案，而是直接验证鼠标模态操作是否成立。

## 唯一产品问题

加入世界 XY 网格与透视 / 正交投影后，研究人员能否始终判断视角方向、深度、精确变换、刚体选区，以及哪些未选 residue 因显式衰减权重而改变坐标？

本原型只对应 docs/2026-08-29-webui-functional-spec.md 第 3.11 节，并保持第 3.4、3.5、3.8、3.12 节的 Prompt Studio 语境。它不裁决正式结构边界检查、自动优化算法、最终视觉、完整快捷键表、协议或生产架构。

## 结论

**已通过，2026-08-30。** 用户确认本原型可以作为后续产品实现的交互依据。

通过范围包括：Blender 风格鼠标模态 G/R、Global / Local 坐标系、O 衰减编辑、世界 XY / Z=0 网格、Z-up 视角、Perspective / Orthographic 与小键盘 5 切换、残基级选择和按需显示的坐标状态。原型中的 Local frame 构造与 O 距离规则仍是待写入正式功能规格的暂定定义。

## 运行

直接双击 index.html，或运行：

    .venv/bin/python .scratch/webui-product-definition/prototype-5-residue-structure-editing/serve.py

打开 <http://127.0.0.1:4183/>。所有状态只存在内存中，刷新即重置。

1CRN chain A 的 sequence identity 用于真实蛋白质研究语境；视口中的 N、CA、C、O、CB 坐标及边界均为明确标注的交互示意，不形成科学判断或产品默认值。

## 操作模型

- 空闲时左键选择 residue；拖拽框选；Shift 选择连续区间；Ctrl/Cmd 追加或切换不连续 residue。
- 中键拖拽旋转视角，Shift + 中键平移，滚轮缩放。
- 默认使用 Perspective。小键盘数字 5 在 Perspective / Orthographic 间切换，顶部始终提供同一动作的可见按钮；普通数字行的 `5` 仍是 G/R 的精确数值输入。
- Perspective 使用真实深度缩放：近处结构与原子更大、远处更小，XY 平行网格线向远方收敛。Orthographic 关闭远近缩放，世界平行线保持平行。
- 视口网格是真正固定在世界 Z=0 上的 XY 平面，不是屏幕背景纹理。相机采用 Z-up 轨道；中键旋转、平移和缩放时网格与结构使用同一个投影。
- 世界 X=红、Y=绿；网格原点标记 `XY · Z=0`，左下角 Global gizmo 在网格接近侧视、只剩窄线时仍提供三轴方向参照。
- 选择后按 G 或 R，不按住鼠标直接移动，即时驱动刚体预览。
- Global 使用固定 ProteinPrompt 世界 X/Y/Z；Local 使用当前 residue selection 的暂定局部框架。两者都可在变换前或变换中切换。
- 单 residue 的 Local 暂定为 X=N→C、Z=N–CA–C 平面法向、Y 构成右手系。多 residue 暂定为 X=首末所选 CA、Z=所选 residue 平面法向平均、Y 构成右手系。
- 变换中按 X/Y/Z 约束当前坐标系的轴。直接键入数字可精确覆盖当前鼠标量值，但不是开始变换的前提。
- O 开关衰减编辑。当前暂定使用 3D CA 到最近所选 CA 的距离；平滑、线性和恒定三种曲线可切换。
- O 开启且 G/R 进行中时，滚轮调整 Å 半径；所选 residue 权重固定为 100%，半径内未选 residue 按显示权重接受部分变换。O 关闭时滚轮仍缩放视角。
- 视口左键或 Enter 确认；视口右键或 Esc 取消；Ctrl/Cmd+Z 撤销。
- 可见按钮与快捷键进入同一状态机；不存在单独的“表单变换”路径。
- S 缩放和原子选择会被明确拒绝。O 影响是用户显式指定的坐标编辑，不执行自动优化、能量最小化或结构修复。

## 引导走查

页面底部提供五个始终可见的 walkthrough tabs：

1. 投影：在 Perspective / Orthographic 间切换，比较结构远近大小和网格收敛，同时核对坐标与历史不变。
2. Global / Local：对 A:15 V 分别使用 Global X 和 Local X，比较世界轴向量与变换分量。
3. Local 刚体：对 A:8–10 + A:23 + A:31–33 使用 Local R+Z，核对不连续选区的局部框架和刚体误差。
4. O 衰减编辑：对 A:15 V 开启 O、进入 G、用滚轮改变半径，检查未选 residue 权重、确认和撤销。
5. 取消与禁止：进入 G 后用右键 / Esc 取消，再尝试 S 和原子选择。

## 原型边界

- 最小选择单位始终是 residue identity。原子点位用于证明一个 residue 的全部示意原子共同接受变换，不能单独选择。
- 多个连续或不连续 residue 共享选择中心和一个精确刚体变换；右侧显示的内部距离误差是几何交互证据，不是正式科学检查。
- O 关闭时只有选区移动。O 开启时选区仍保持 100% 刚体变换；每个受影响的未选 residue 内部原子接受同一部分变换，但不同权重 residue 之间不再组成一个共同刚体。
- Local 构造规则与 O 的 3D CA 距离规则只是本轮可操作定义，尚未成为权威功能规格或科学规则。
- 黄色虚线边界只显示选中 / 未选的链内相邻关系。其数量和表达是示意，不是正式结构合理性判定。
- “保存 ProteinPrompt”只模拟明确保存边界，不写回 Workflow 或任何持久化存储。

## 浏览器走查记录

浏览器实际走查完成于 2026-08-30：

- 刷新后默认状态明确显示 `透视 / Perspective`、远近缩放开启。结构近端原子与间距变大、远端变小，XY 网格线随深度向远方收敛。
- 使用顶部 Num 5 同路径按钮切到 `正交 / Orthographic` 后，结构不再产生远近缩放，XY 网格恢复平行；再次切回 Perspective 可逆，selection、已确认坐标和历史均未变化。
- G 模态中普通数字行 `5` 仍得到精确 `5 Å` 输入且不会切换投影；投影动作走单独的 `Numpad5` code 分支。切换投影后该数值覆盖保持 `5 Å`，Esc 取消后历史深度仍为 0。
- 初始视角中，世界 XY 网格呈有方向的斜面而不是屏幕水平/垂直背景；红色 X 与绿色 Y 穿过世界原点，并显示 `+X`、`+Y`、`XY · Z=0`。
- 实际使用中键把视角从右前方旋转到另一方向后，全部细网格线、主网格线、X/Y 轴和原点标签共同改变投影角度；结构与网格的相对世界位置保持一致，左下角 Global gizmo 同步旋转。相机变换未改变 residue selection 或结构编辑历史。
- 旋转视角后再次按 G 并移动鼠标，状态仍进入 `G · MOVE`，来源仍为鼠标实时预览；取消后恢复 IDLE，说明网格/相机修正没有破坏模态变换状态机。
- 单残基 A:15 V 进入 G 后不输入任何数值，只移动鼠标即得到实时三维位移。加入 X 约束后，继续移动鼠标得到 ΔX +4.784 Å、ΔY/ΔZ 0.000 Å；右侧持续标明“鼠标实时预览”和“数值键未使用”。
- 视口左键确认把当时鼠标位置对应的精确位移写入历史，Ctrl/Cmd+Z 后坐标、modified residues 和历史恢复。
- A:8–10 + A:23 + A:31–33 共 7 residues、3 groups、34 个示意原子进入 R，再约束 Z；移动鼠标得到 +18.959° 预览。选区内部成对距离最大误差约 7.11e-15 Å，6 个选中 / 未选相邻边界持续显示，未选邻居没有随动。
- 变换中点击残基矩阵不会改变选择，而是明确提示选择已锁定。视口右键和 Esc 都会丢弃预览，撤销深度不增加。
- 直接键入 -2.5 可把鼠标驱动的 Y 位移精确覆盖为 -2.500 Å；数值输入是可选覆盖，不是 G 的前置步骤。
- 矩阵中的 Shift 连续区间与 Ctrl/Cmd 不连续追加已走查；视口左键拖框实际选中多个 residue identities。
- 中键拖拽、Shift + 中键拖拽和滚轮分别改变视角旋转、平移和缩放，不改变 residue selection 或结构编辑历史。
- S 只产生“不支持缩放”反馈，不创建操作。浏览器 console 没有 error 或 warning。
- Global G+X 实际显示轴向量 [1.000, 0.000, 0.000]，鼠标位移只产生世界 ΔX。
- 同一 A:15 V 切换 Local 后，G+X 实际使用 [-0.864, 0.455, 0.216]；鼠标位移同时产生世界 ΔX、ΔY、ΔZ，视口局部 gizmo 与角落固定 Global gizmo 指向不同。
- 不连续 7-residue 选区的 Local Z 暂定轴为 [-0.350, -0.937, 0.014]；R+Z 的内部成对距离最大误差仍约 7.11e-15 Å。变换中切回 Global 后，同一个 Z 约束立即变为 [0,0,1]。
- A:15 V 开启 O、半径 8.0 Å、平滑曲线时，A:13、A:14、A:16、A:17 分别显示约 2%、53%、52%、1% 权重。变换中滚轮把半径增至 8.8 Å 后权重立即重算；切换线性曲线后显示约 16%、57%、56%、13%。
- 确认 O 变换时，历史明确记录 1 selected + 4 falloff，modified residues 包含 A:13–17 中实际受影响的位置；撤销后坐标、历史和 modified 标记恢复。

## 当前观察

- ResidueLayout 的“坐标状态”行不再为每个 residue 重复显示无信息量的 `xyz`。空闲未修改状态保持空白，只在 O 预览时显示影响百分比、确认修改后显示 `MOD`。
- 透视与正交现在是明确的内存视图状态，不进入结构坐标历史。投影中心处保持相同显示尺度，因此切换时不会发生无关的整体缩放跳变；差异只来自真实深度。
- 旧版网格按画布像素绘制，因此无论怎样旋转视角都保持屏幕横竖方向。本次改为对世界 XY 平面上的三维网格点使用与结构相同的相机投影，并加入随缩放自适应的 1/2/5 间距。
- 本次重写修正了原版本最关键的模型错误：G/R 不再创建带默认值的表单操作，而是进入鼠标模态；数值只在用户主动键入时覆盖当前鼠标量值。
- 视口、共享 ResidueLayout 轴和右侧状态面板现在共享同一选择和变换状态；可见按钮与快捷键不存在分叉。
- 规格 3.11 目前只写 X/Y/Z 约束，没有定义 Global / Local，也没有定义 Local frame 的来源。如果采用本原型，需要把最终 Local 构造规则写入功能规格。
- 规格 3.11 也没有定义默认投影或小键盘 5。如果采用本原型，需要明确 Perspective 为默认视图、Orthographic 为可逆视图状态，且投影切换不属于结构编辑历史。
- 规格 3.11 目前写明“不自动移动邻近残基”。本原型把 O 定义为用户显式开启、带半径和权重证据的坐标操作，因此不是自动移动；但它确实改变未选 residue。若采用，仍需在功能规格中明确增加这一例外及其距离、连接范围和衰减曲线。
- 正式边界科学检查仍是规格第 8 节的未决事项。本原型只表达“选中 / 未选链内相邻边界”，不能回写为科学规则。
