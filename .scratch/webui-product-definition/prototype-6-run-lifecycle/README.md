# 运行范围与生命周期（一次性原型）

最后更新：2026-09-21

本目录保留内存交互原型，用于比较布局与操作可读性；刷新即重置。原型未连接生产后端，其中的模拟数据、接口和保存流程不定义当前产品协议。生产行为以[Run 范围规格](../../../docs/2026-09-17-run-scope-spec.md)及[WebUI 运行说明](../../../webui/README.md)为准。

## 界面方向

方案 A「空间范围叠层」：画布直接高亮执行范围，收起节点显示状态，侧栏集中展示范围、节点详情和 Run 事件。方案 B「运行账本」和 C「分支泳道」用于布局比较。

## 运行

从仓库根目录运行：

```bash
.venv/bin/python .scratch/webui-product-definition/prototype-6-run-lifecycle/serve.py
```

打开 <http://127.0.0.1:4184/?variant=A>。使用 `?variant=A/B/C` 切换布局。

## 交互观察

选择运行范围并使用手动推进、模拟失败和取消控件，观察画布状态、详情与结果来源提示是否清楚。

示例蛋白质、结构几何、参数、分数与来源标识只服务于交互演示。原型不能作为科学验收、持久化或生产接口测试的依据。
