# Results Workbench（一次性原型）

最后更新：2026-09-21

本目录保留内存交互原型，用于比较布局与操作可读性；刷新即重置。原型未连接生产后端，其中的模拟数据、接口和保存流程不定义当前产品协议。生产行为以[结果浏览规格](../../../docs/2026-09-17-result-explorer-spec.md)及[WebUI 运行说明](../../../webui/README.md)为准。

## 界面方向

方案 B「谱系工作台」：以父结构、子代序列和再次折叠结构的来源关系为主轴，候选账本作为相邻索引。方案 A「候选账本」和 C「审阅篮」用于布局比较。

## 运行

从仓库根目录运行：

```bash
.venv/bin/python .scratch/webui-product-definition/prototype-7-results-workbench/serve.py
```

打开 <http://127.0.0.1:4185/?variant=B>。使用 `?variant=A/B/C` 切换布局。

## 交互观察

观察候选焦点、勾选集合、表格筛选、比较视图和来源面板；导出按钮仅演示交互，不生成真实结果包。

示例蛋白质、结构几何、参数、分数与来源标识只服务于交互演示。原型不能作为科学验收、持久化或生产接口测试的依据。
