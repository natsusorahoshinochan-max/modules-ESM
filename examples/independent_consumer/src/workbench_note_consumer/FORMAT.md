# Public count format

`example.count`: `entry` names a UTF-8 file containing the decimal number of Unicode characters in the input note. `sample/count.txt` is a valid entry.

The input contract is the producer's public [example.note format](https://github.com/natsusorahoshinochan-max/modules-ESM/blob/codex/issue144-integration/examples/external_module/src/workbench_notes/FORMAT.md). This package implements that format directly using the public package reader.
