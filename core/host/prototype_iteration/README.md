# 一次性原型：任务批次与通用编排

状态：用于比较模块边界的可执行演习，尚未接入生产执行器。蛋白生成、评价和包保存均为内存模拟。

## 要回答的问题

任务模块一次处理多个模板，与载体对明确的包列表逐项调用任务，能否在相同参数下产生相同的成功结果？发生失败、取消、筛选和跨轮交接时，哪些状态必须由任务解释，哪些由载体管理？

## 运行

双击同目录的 `index.html`。文件不需要网络、服务或依赖安装；刷新页面清空演习。自由操作可改变组织方式、筛选作用域和参考交接方式；引导演习按步骤展示完整相关状态。

验证嵌入 HTML 的同一份纯逻辑：

```sh
node core/host/prototype_iteration/check.mjs
```

用户明确要求执行测试，因此本原型包含有限的合同和状态检查。

## 比较的边界

| 方案 | 载体看到的生成调用 | 任务内部仍负责 |
|---|---|---|
| 任务整批 | 一个调用接收两个模板包 | 读取模板、每模板三个请求、顺序、部分结果与私有续算 |
| 载体逐包 | 两个调用，各接收一个明确包 | 同样读取模板、每模板三个请求、顺序、部分结果与私有续算 |

工具内部的张量批处理未模拟，仍是独立于上述两层的适配与计算问题。载体 map 按用户明确给出的包列表组织任务调用，不能据此拆开任意科学包内部的对象。

公共函数候选：

- `Host.calls(runId, iteration, node, inputGroups, parameters)` 固定每个调用的输入和参数，分配轮次、条目、节点作用域内的身份。
- `Host.drive(calls, invoke)` 执行本演习的串行调用，跳过同一运行内已成功项；失败或取消后暂停。
- `Host.release(calls)` 仅在全部调用成功后交付有序输出包列表。
- `Host.carry(boundaryOutputs, bindings)` 按明确端口绑定将包列表带入下轮。
- 任务返回 `status / outputs / continuation`。载体保存 continuation 并原样交回，任务解释内部请求进度。

`Host` 函数不读取包内容。任务模拟函数负责包内数值、来源模板、参考、分组和筛选。测试使用读取即抛错的不透明对象，检查载体没有偷偷解释科学字段或私有续算内容。标量操作通过同一调用器处理 `external.scalar` 包，数值为 1 和 7，加 10 后得到 11 和 17。

## 独立可核算的输入与结果

两个模板值为 2、8；每个子项分别加 −1、0、1。参考初值为 6，评价公式为 `10 - abs(value - reference)`。第一轮六个值为 `[1, 2, 3, 7, 8, 9]`，分数为 `[5, 6, 7, 9, 8, 7]`。这些演算值仅用于检验执行行为。

| 演习参数 | 第一轮选中值 | 第二轮选中值 / 行为 |
|---|---|---|
| 阈值 7，全局最多 2，固定参考 | 7、8 | 6、7 |
| 阈值 7，每模板最多 1，固定参考 | 3、7 | 4、6 |
| 阈值 6，每模板最多 2 | 3、2、7、8 | 下一轮四次任务调用，共生成 12 项 |
| 阈值 6，全局最多 2 | 7、8 | 下一轮两个模板 |
| 阈值 7，全局最多 2，携带首项参考 | 7、8 | 新参考 7，最终 7、7；两个独立对象保持输入顺序 |
| 阈值 99 | 空 | 第二轮仍为空，无自动补足 |
| 第二模板第二请求失败 | 四个可查看结果，无下游交付 | 继续仅重试失败及未开始请求，成功项不重复 |
| 第二模板第二请求前取消 | 四个可查看结果，无下游交付 | 继续后六个请求各成功执行一次 |

运行中修改画布草稿会被拒绝；失败、取消或结束后可以修改。生成失败后修改草稿的每模板数量为 5，再继续旧运行，旧调用仍使用数量 3。两次以相同配置启动的新运行各自执行全部请求，没有按输入等价复用。

## 原型结论与待验证边界

这组演习支持把“按明确包列表调用”和“按具名端口重复子流程”留在通用执行层，同时让任务模块持有科学对象拆分、实际请求批次和请求续算。两种调用组织在成功路径上可等价，调用失败的粒度不同，需要在运行界面显示实际调用身份和任务内进度。

继续验证时需解决：实际公共端口如何表达子流程输入与输出；任意任务输出格式由哪个明确模块转成包列表；并行 map 的取消和汇合；文件接收失败时进度与交付的原子提交；真实工具的随机状态与私有请求计划。此页面没有实现并发、进程终止恢复、文件交付、真实工具调用或生产 API 修改。

固定参考、携带参考、串行暂停与空列表继续执行，都是本演习明确选择的连接和参数，用来检验边界。模块及载体仍需支持用户通过公开操作组合真实流程。
