要回答的问题：通过明确的包列表、子流程边界和端口连线，能否表达“每个模板内筛选”与“汇总后筛选”，以及固定或更新参考的两轮流程？

把筛选放进逐项子流程，或者放在汇总节点之后；让下一轮输入和参考沿明确的反馈连接传递。执行器只读取图和包列表；生成、评价、合并、拆分和筛选由各节点解释内容。

此页的两轮蛋白演习使用教学数值，生成与评分均为模拟。真实数据回放只读取已计算的评价，页面不调用模型。所有编辑和运行结果留在内存。
