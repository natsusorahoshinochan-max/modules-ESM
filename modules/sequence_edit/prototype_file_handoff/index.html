此页面导出的任务参数由命令行桥接交给真实 ESM SDK。实验说明：ESM 文件输入；PDB/mmCIF 解析与转换。上方引导演习是可交互的逻辑运行；以下为已保存的真实工具执行结果。
实际执行观察
完整 ESM3 序列生成三种条件配置均生成 58 位序列，固定前五位 MTYKL；实际 forward 只接收选择的 55 或 5 位骨架。
ESM3 条件模式默认坐标模式使用 4096 掩码；关闭后保留新增位置的 2246 编码，实际 logits 和序列均改变。
11 个文件交接场景复现插入码丢坐标、编号跳跃补位置、多构象原子混用等差异；四种输入经显式选择和小映射正确回读。
此处没有结构生成或折叠评价。生成结果中原样携带的坐标仍是输入条件。单步采样用于验证交接和模型输入，生物学效果尚待评价。
