一个会改变接口设计的实测发现

本次 ESM-3 结构编码中，新增位置的坐标为 NaN，但其结构 token 为 2246，原生 mask ID 为 4096。坐标缺失与生成时的掩码处理需要分别表达，并依据实际生成接口验证。长度和张量尺寸正确，只是检查的一部分。

这轮实验支持怎样的设计？

两种条件存储形式都能正确交接，内部表示仍可选择。任务形状的工具接口能把模型专属编解码集中到工具实现。载体逐项调用与任务内部批次可以同时存在；轮次交接必须保持明确的调用身份与成功边界。

并行调度、文件提交与续算的原子性、独立作者接入，以及完整真实生成—预测—筛选循环，仍需后续验证。

此页面用于审查候选设计。原型位于独立实验分支，正式模块的接口需根据实验结果进一步确定。
