# 画布工作台：第一阶段原型

状态：可丢弃原型，采用已选定的 A 全画布方向。用于验证节点编辑手势，不进入正式执行与保存路径。

要回答的问题：用户能否直接在画布上放置节点、编辑参数、断开和改接连线，并通过撤销恢复操作？

## 启动

在仓库根目录运行：

```sh
npm --prefix webui run prototype:canvas
```

打开 `http://127.0.0.1:5174/?prototype=canvas`。开发入口使用 `prototype=canvas`，正式构建不开放该入口。

## 设计

北极星：流程始终是工作区的主角，参数贴近节点，管理功能退后。

画布占满固定顶栏与状态栏之间的空间，节点库按需打开；属性在节点内向下展开。展开和收起保持所有节点坐标不变；发生重叠时由用户移动或收起节点。常用参数保留在紧凑节点中，附加参数与端口格式放在展开区。

参考用户提供的 ComfyUI 与 Blender 图，采用深色画布、左入右出、紧凑字段与按格式着色的曲线；沿用本项目明确格式转换与模块职责。

面向桌面研究工作台，主要查看尺寸为 1280×720 与 1440×900。窄窗口默认以 90% 查看局部图，通过平移浏览；适应全图由用户触发。页面自身不滚动。

视觉使用系统中文无衬线，画布 #1b1e1d、节点 #282c2a、选中轮廓 #b1d4be。节点库与节点属性淡入，适应视图连续变换，连线随选择淡化；拖动直接跟随指针，减少动态效果偏好关闭过渡。

## 节点与参数

- 从节点库拖到画布，松手放置；拖到工具栏或节点库取消添加。
- 点击节点库条目后，在画布点击选择落点；`Esc` 取消。双击空白也可打开节点库。
- 只拖节点标题移动节点；输入框、开关和端口分别处理自己的操作。
- 工具使用下拉选择，再次点击同一按钮、点击外部或按 Esc 收起。方向键浏览、Enter 确认；选项来自该节点的固定工具声明。切换工具保留公共参数，工具专属参数采用新工具的默认值。
- 数字使用带范围的数字输入，越界或留空后离开字段恢复原值；布尔值使用开关，派生信息只读。
- 点击“属性”或双击标题，在当前节点下方展开、收起。

## 连线

- 连线拖动只从端口圆点触发，端口文字不触发拖线。拖输出圆点创建分支，已有输出分支保留；也可从空输入反向拖到输出。
- 拖已连接的输入端口移走原连线：松到兼容输入改接，松到画布空白断开。
- `Esc` 或失去窗口焦点取消当前手势，恢复原状态。
- 兼容端口高亮并在靠近时吸附。输入已有连线、绑定了文件、格式不兼容、自连或形成循环时，提示原因并保留原连接。
- 格式兼容依据输入声明，不做隐式转换。节点上的文件绑定可用旁边的 × 移除。
- 点击连线后可按 Delete/Backspace 或点击“断开”，只删除该条连接。

## 导航与历史

- 空格拖动、中键拖动、双指滚动或平移工具移动画布。
- 捏合、Ctrl/Alt 滚轮、加减按钮缩放；缩放围绕指针或视口中心。
- `F` 聚焦选中；`Shift F` 适应全图；`0` 恢复 100%。
- 点击、Shift 追加和空白框选；多节点一起拖动。复制保留所选节点间的连线。
- 添加、移动、复制、删除、连线修改、参数修改和工具切换可撤销与重做，保留最近 40 步。一次完整手势计为一步，取消手势不新增历史。
- “查看状态”展示视口、选择、展开节点、完整图与历史长度。

快捷键使用 `Cmd` 或 `Ctrl`：`Z` 撤销、`Shift Z` 重做、`D` 复制、`A` 全选；普通 `A` 打开节点库，`V/H` 切换选择和平移。
