# 画布工作台：第一阶段原型

状态：A 全画布交互方案已采用，正式实现遵循[画布工作台交互需求](../../../docs/requirements.md#画布工作台交互)。此目录保留可丢弃原型代码，供实际操作与对照。

## 启动

在仓库根目录运行：

```sh
npm --prefix webui run prototype:canvas
```

打开 `http://127.0.0.1:5174/?prototype=canvas`。开发入口使用 `prototype=canvas`，正式构建不开放该入口。

## 设计

北极星：流程始终是工作区的主角，参数贴近节点，管理功能退后。

面向桌面研究工作台，主要查看尺寸为 1280×720 与 1440×900。窄窗口默认以 90% 查看局部图，通过平移浏览；适应全图由用户触发。页面自身不滚动。

视觉使用系统中文无衬线，画布 #1b1e1d、节点 #282c2a、选中轮廓 #b1d4be。节点库与节点属性淡入，适应视图连续变换，连线随选择淡化；拖动直接跟随指针，减少动态效果偏好关闭过渡。

## 操作入口

行为规则集中维护在需求中；原型提供以下操作入口。

| 操作 | 输入 |
| --- | --- |
| 平移 | 空格拖动、中键拖动、双指滚动或平移工具 |
| 缩放 | 捏合、Ctrl/Alt 滚轮、加减按钮 |
| 聚焦选中 / 适应全图 / 100% | `F` / `Shift F` / `0` |
| 追加选择 / 框选 | Shift 点击 / 空白拖动 |
| 打开节点库 | 添加节点按钮、普通 `A` 或双击空白 |
| 展开、收起属性 | 节点的属性按钮或双击标题 |
| 浏览、确认工具选项 | 方向键 / Enter |
| 删除选中节点或连线 | Delete / Backspace |
| 撤销 / 重做 / 复制 / 全选 | Cmd 或 Ctrl 配合 `Z` / `Shift Z` / `D` / `A` |
| 选择工具 / 平移工具 | `V` / `H` |
| 取消当前操作 | `Esc` |
| 检查内存状态与历史 | 底栏“查看状态” |
