# Retired Protein Workbench frontend

This directory contains the retired graphical client. It is not a current
product implementation, deployment component, contract owner, or verification
target. Do not extend, build, or use this source as the basis for the replacement.

The replacement frontend will be created from an empty directory and will remain
an independent client of the versioned public protocol. Its active, nonnormative
design material is maintained in:

- [`docs/2026-08-18-frontend-rewrite-discussion-design.md`](../docs/2026-08-18-frontend-rewrite-discussion-design.md)
- [`docs/research/2026-08-18-frontend-backend-contract-separation.md`](../docs/research/2026-08-18-frontend-backend-contract-separation.md)

This entire retired implementation is expected to be deleted when replacement
work begins.
