# Protein Workbench 需求

状态：以下为已确认要求。目标设计见 [architecture.md](architecture.md)。

## 本次重构的六组核心需求

### 1. 目标与推进方式

用户通过可视化画布连接节点，自主组织数据导入、编辑、生成、结构预测、评价、分析、筛选及重复迭代。研究对象、工具、参数、顺序、分支、分组、参考和筛选策略由用户决定。

面向整个项目删除科学值机制及已确认的旧机制，解除载体与模块的双向依赖，保留已确认的科学功能。围绕实际功能和调用路径完成必要设计，逐段替换实现、更新调用方并删除旧路径。以蛋白质设计长流程作为测试、演习和实施主线，检验可组合能力；案例中的固定步骤、工具、数量和研究策略不写成软件机制，重构范围覆盖全项目已确认功能。

接口与格式随真实调用需要具体化，不将全部接口、格式预先定稿作为开工条件。

### 2. 删除科学值机制

删除现有科学值机制及其强制追溯依赖，不建立替代追溯框架或预留体系。

序列、结构、分数及使用它们必需的对象和位置对应关系继续存在，由具体模块负责。不得按名称整块删除，也不得把旧机制整体搬进模块。

### 3. 载体与模块的职责

载体按模块公开声明提供编排、运行和通用数据管理；科学操作与专用界面由模块提供。职责与交接集中维护在[目标架构](architecture.md#职责与依赖)。

载体不内置或强制统一蛋白、候选、评分、残基轴等科学模型，不重写科学身份或补写科学元信息。

保存只检查通用交付完整性，不以科学内容作为准入条件，也不通过注册器、回调或插件验证器间接检查。

模块缺少必需输入或执行失败时，停止本次操作并报告原因，不修补输入、猜测对应关系或改变任务。不另建统一的运行前科学检查系统。

### 4. 模块之间的数据交换

官方与外部模块遵守同一套公共接入约定。作者可以自定格式，不必使用项目统一科学类。

输入端口声明接受哪些格式，输出端口声明交付什么格式。载体按声明判断连接；接收模块检查某次操作的实际适用条件。载体不推测科学含义或隐式转换，不兼容时由用户明确选择转换节点。

输出交付公开格式承诺的内容及必要文件。接收模块无需查上游实现、工具或生成历史。数据交换不要求安装生产模块；自愿复用其公开代码时才产生明确安装依赖。

### 5. 模块实现与工具替换

`datatypes/` 中有用的科学实现归入具体模块，不再单独维护公共科学基础层。模块可以自愿复用其他模块的公开能力，不依赖其私有实现或官方特权。

科学操作模块按[功能清单](#科学模块的功能范围)组织，一个模块可以提供多个节点。序列与条件编辑、结构处理分别可安装。模块分工与交接见[目标架构](architecture.md#职责与依赖)。

一个操作可以选择多个符合其公开调用约定的工具，同一工具可以服务多个操作。外部作者提供符合约定的工具实现时，无需修改原操作节点。工具实现的归属按真实消费者确定，不依赖其他任务模块的私有实现。

同一节点可允许任务范围不同的工具。选中工具后明确限制；不支持当前输入时停止，不丢弃配体等输入或更换任务。成功输出必须满足节点格式承诺，不填造工具无法提供的内容。参数按实际接口传递，不按同名参数猜测互换。

### 6. 保存与旧系统清理

自定义格式须可靠保存。跨项目采用由载体保证内容及必要文件独立可用，删除来源项目后仍可使用。保存与采用不沿上游历史补科学资料，不执行科学证据闭合检查。

旧运行结果、旧项目配置和旧画布可删除，不迁移；用户导入的原始研究文件保留。不保留旧解析器、兼容层或双轨实现。

删除项目自建的数据、接口、协议版本管理和历史兼容机制。保留工具实际运行所需的型号、模型信息与依赖安装约束。

不保留命名流程版本、特化的三方比较及插入环阈值分类。普通结构比较、区域选择及相关评价继续按已确认范围保留。

#### 删除项目自建哈希机制及附加记录

删除我们自行建立的全部哈希机制及附加记录，包括用于身份生成、存储寻址、结果匹配、缓存复用、科学引用、协议校验和文件完整性校验的摘要计算与字段。同步删除相关调用、声明、界面展示、测试及文档内容，不保留兼容路径。

不以其他哈希算法、内容指纹或改名字段替代，也不将旧机制搬入模块。

#### 身份、历史结果与续算

对象和存储记录使用独立分配的普通标识，文件通过明确记录和包内文件键定位，不以内容摘要作为身份。

删除自动识别等价输入或等价计算并复用历史结果的机制。保留用户明确选择历史结果作为输入，以及针对指定运行未完成请求的续算。改变输入或计算参数时，按新计算处理。

#### 随机操作

自有模块删除通过哈希派生 seed、进行抽样排名或生成编辑身份的实现。保留随机生成、编辑和抽样功能，使用明确的 seed 和随机数生成器，正确传递用户指定的 seed。

#### 保存与跨项目采用

保存与跨项目采用仍须确保声明文件到齐、可读取，且实际写入与提交成功；失败时报告具体原因，不将未完成的交付报告为成功。

不建立内容摘要校验、重复读取比对或周期性完整性审计机制。

#### 外部工具边界

外部工具自身强制要求的行为，按其接口正常执行，不扩展为项目公共机制。

## 仍有效的产品行为

以下要求约束重构后的功能，不规定现有类、字段或存储表示。

### 项目、模块与界面

- 没有启用科学模块时，载体仍能启动、创建、打开和保存项目、显示画布并管理模块。
- 用户可以选择模块包安装并启用，也可禁用、卸载或重新安装。官方功能模块默认附带并启用，不因此自动下载模型或填写凭据。
- 提供应用内模块设置。模块声明远程凭据、后端可访问的已有模型位置、服务地址或外部程序位置等配置，载体展示、保存并提供给模块。部署配置与节点计算参数分开，用户无需修改环境变量或启动脚本；不包含自动下载模型或安装计算环境。
- 缺少模块仍可打开项目，保留节点、连线和配置并标明缺失；相关节点不能运行。安装并启用所需模块后恢复使用，不要求载体理解其科学内容。
- 模块专用界面使用公共 React 接口及明确的共享依赖安装约定。官方与外部模块均可提供编辑器、查看器和后端读取能力，自定义数据无需伪装成内置蛋白类型。
- 同一格式允许多个查看器，打开时使用默认查看器，用户可以切换；不能按加载顺序覆盖。切换不改变计算结果。
- 默认打开教学实例，允许尝试编辑。第一次手动保存时创建用户自己的项目；编辑先留在内存，教学原件保持不变。
- 复制项目包括流程、参数、所需输入和布局，不复制运行记录与结果；副本从未运行状态开始。已明确采用的输入属于所需输入。

### 前端视觉

载体、节点画布、模块面板和 Protein Studio 统一采用已确认的亮色设计。颜色、选中状态和三维明暗规范集中维护在[前端视觉规范](frontend-design.md)。

### 画布工作台交互

采用 A 全画布方案，以 ComfyUI、Blender 式节点工作台作为界面方向。已确认原型的启动方式与参考快照见[原型说明](../webui/src/canvas-prototype/README.md)。

- 画布占据主要工作区，节点库按需打开；支持平移、缩放、适应全图、聚焦选中、单选和多选。
- 节点保持紧凑，常用参数直接显示。点击节点的“参数”在原位置向下展开，再次点击收起；不用独立的右侧节点属性框。展开、收起均保持所有节点坐标不变，重叠由用户移动或收起节点处理。
- 节点库支持拖到画布放置，也支持点击条目后选择放置位置。拖动节点标题移动节点，参数控件处理自身编辑。
- 连线采用左入右出的曲线，按端口格式区分颜色。只有端口圆点触发拖线，旁边文字不触发。
- 从输出圆点拖线创建分支，保留已有分支；拖动已连接的输入圆点，松到兼容输入改接，松到画布空白断开。不兼容或被占用的目标提示原因并保留原连接；取消手势恢复原状态。
- 工具使用下拉选择，再次点击同一按钮、点击外部或按 Esc 收起，支持键盘选择。参数按类型使用数字输入、开关等控件，派生信息只读。
- 添加、移动、复制、删除节点，连接、断开、改接连线，以及参数和工具修改支持撤销与重做。一次完整编辑手势计为一步，取消手势不新增历史。

### 画布、文件与结果界面

采用方案 A：项目菜单、保存、运行和撤销集中在一层顶栏；项目名称只显示一次，画布保持主要工作区。节点名称、端口与按钮使用简短业务用语，移除常驻手势说明、内部标识和重复标题。

文件从对应导入节点选择；节点显示文件名和必要选项。结果按运行、节点及输出组织，在画布右侧查看内容、已有指标和必要状态，可定位节点、下载或明确采用到后续节点及其他项目。结果面板不再混入手动接线表单和临时筛选墙。

节点参数在节点内部展开，以类型明确的控件编辑；常用项直接呈现，更多参数折叠。筛选使用已有分数、参考对象、阈值、方向和数量控件。默认查看器展示数据内容，补充操作按需展开；内部格式标识、包编号和原始 JSON 不作为默认展示。

### 界面语言

- 正式前端支持简体中文与英文，顶栏和 Studio 提供语言切换。首次按浏览器语言选择：中文使用简体中文，其他语言使用英文；用户选择保存在当前浏览器。
- 切换立即更新载体、节点、端口、参数、模块编辑器和查看器的界面文案，保留画布位置、选区、展开状态、未保存内容及 Studio 撤销记录。
- 项目名、文件名、用户填写内容、残基符号、科学指标、参数值和交付数据保持原样。外部工具的原始诊断保留原文。
- 模块提供自己的界面翻译；只有单语言名称的外部模块显示其原文。中英文均使用简短用语，英文布局允许必要换行。

### 流程组合与迭代

- 图形画布支持放置、移动节点并连接端口，显示计算依赖、结果和失败位置。操作可以独立使用，也可以组合为不同顺序、分支和多个参考的流程。
- 用户可以组织子流程，对每个明确输入执行同一子流程，并指定重复轮数；各轮结果可以查看、采用和导出。子流程的输入、输出及反馈由用户明确连接。
- 逐模板筛选与全体候选共同筛选，通过子流程作用范围、集合操作和筛选节点的位置表达。每模板生成数量、筛选指标、阈值、排序方向及数量上限均由用户配置。
- 固定参考通过明确输入传入；随轮次更新的参考通过明确反馈传入。历史候选可以作为明确输入参与后续选择，执行时不自动寻找最新参考或按生成历史决定分组。
- 流程可以从独立导入、历史结果或其他模块的输出开始。多模板、多轮流程沿用[编辑、保存与运行](#编辑保存与运行)中的保存、失败和续算行为。

### 编辑、保存与运行

- 用户手动保存，不自动保存。流程与布局须一起成功才算保存成功；不完整流程也能保存、重开继续编辑。
- 运行时按画布连线划分互相连接的节点组，每组独立检查。组内任一节点未正确配置，则整组不运行并指出原因，不影响其他配置完整的独立组。无连线的单个节点也独立判断。用户可通过断线拆分节点组，先运行准备部分，再根据结果继续编辑，无需新增专门的局部运行操作。
- 未保存退出时提醒，允许放弃离开或取消继续编辑，不提供“保存后退出”。浏览器关闭或刷新使用原生提醒，受浏览器触发条件限制。
- 有未保存修改时运行，须提示先保存；用户选择“保存并运行”且保存成功后才启动。取消或保存失败时不运行。
- 同一项目运行期间禁止修改，结束或取消后恢复；允许查看结果。
- 计算在后端执行，关闭前端后任务继续运行。
- 节点失败阻止依赖它的后续计算，独立分支继续。明确区分失败和因依赖失败未执行，不能将整次运行显示为全部成功。
- 提供运行列表和单次结果查看，支持把历史结果直接用于后续计算及跨项目采用，无需导出再导入。不提供跨次运行结果并排查看；结构比较计算仍保留。
- 生成或折叠批次中，一个独立请求用尽适用重试后失败，停止剩余尚未开始的请求。保留已成功结果供查看和导出，标明未全部完成；失败节点的部分结果不自动进入下游。
- 用户可以在相同输入和计算参数下主动继续未完成请求，跳过成功项。改变输入或参数按新计算处理。节点重跑和批内续算是两种操作。
- 远程调用保留适用工具的默认尝试上限，不将某个 SDK 的尝试次数推广为全项目规则或新增自动重跑策略。

### 科学模块的功能范围

正确传递用户指定的数据、对象、位置和参数，并接回所需结果，是科学正确性的标准。科学操作模块按以下 11 项组织；工具实现与载体能力分别按目标架构提供。

| 科学操作模块 | 已确认的用户可用行为 |
|---|---|
| 序列输入输出 | 单条、批量序列导入，序列查看和导出，保留来源及必要标识 |
| 结构处理 | 结构导入、查看和导出，组分保留、链或片段提取、明确的转换与坐标调整，保留来源及真实残基对应 |
| 序列与条件编辑 | 通过独立 Protein Studio 编辑序列、坐标、二级结构、SASA 和功能注释，支持直接编辑、取消、撤销和完成采用 |
| 生成与设计 | 补全、受约束生成、骨架条件设计及工具支持的联合生成，为每个输入生成多个候选 |
| 结构预测 | 预测结构及本次自然产生的置信度 |
| 结构比较 | 对明确候选及参考进行完整结构、链或不连续区域的对应、整体对齐及 TM-score 等指标计算；支持不同长度结构及候选集合，逐对象给出比较结果 |
| 候选评价 | 对已有对象追加可溶性、序列与骨架适配、已有结构独立置信度等评价 |
| 表征计算 | 计算并保存 embedding、逐位置 logits 等真实数值及其位置和列含义，供查看与后续计算使用 |
| 指标分析 | 对已有指标进行区域统计等明确分析 |
| 筛选与排序 | 使用已有评价做条件选择、排序及数量限制 |
| 集合操作 | 对象拆分、合并及选中对象抽取，交付对象和必要文件，供逐模板处理、合并后筛选及后续采用 |

工具自然产生的所需分数随结果保留，不因模块划分要求重新计算。生成结构不冒充独立验证；指定评价区域时保留原结构；统计与筛选不暗中重新运行预测或补算分数。

自有模块间自愿采用一致的区域表达和选择交互，支持指定链上的不连续区域及真实编号对应。这些约定由模块维护，外部模块可自行定义格式。模块提供足以区分评价对象、参考、区域、实际方法和数值含义的数据，不要求用户维护内部映射。

独立导入的序列和结构可以组合评价，所选参考不必是原生成输入。实际生成关系与本次评价关系分别表达，不伪造父子关系。

已决定提供的工具功能中，官方支持、适用且影响计算结果的输入和参数须可配置。默认值有来源，常用和较少用参数可分层展示。

### 工具适配与数值保存

- ESMC 使用 esm 原生接口和 Hugging Face 格式模型，依赖版本由 `pyproject.toml` 与 `uv.lock` 固定。提供可选的整条序列 embedding 和实际逐位置 logits 数值，不以矩阵尺寸代替所请求数值，也不把 logits 表述为概率。
- 本地 ESMC 的整序列 embedding 对实际残基位置求平均，排除特殊 token 和 padding，不宣称与远端 mean embedding 数值等同。逐位置 logits 按新版 tokenizer 处理位置与列编号，保留真实输出列，不将未命名列编造成氨基酸。
- ESMFold2 本地支持 seed，远端接口未公开该参数。本地与远端的参数及默认值分别按实际接口处理，不将本地参数直接套用于远端。
- ProteinMPNN 功能依确认需求与工具接口重做。明确工具解析后的链内顺序位置与真实残基编号、插入码的对应；独立序列评分须检查完整对应，不以部分覆盖后保留旧序列尾部等方式修补输入。Adapter 明确处理 seed=0 的工具语义、生成数量与批大小的关系，以及不同评分 mask 的含义。
- 接受 float16 保存，不要求额外保留原始浮点精度或另建保存路径，也不要求将所有数值字段强制转换为 float16。

### 导入、结构操作与导出

- 单条序列导入遇到多记录 FASTA 时提示使用批量导入，不拼成一条序列。
- 结构导入、导出均支持 PDB 和 mmCIF，用户选择导出格式。Adapter 负责工具所需转换。
- 结构文件逐个导入，不支持一次导入多个结构文件。单文件多个构象可选一个或分别作为候选继续计算。
- 配体、金属、水、核酸等组分在查看、选择和导出时保留，计算接纳范围遵循工具接口，不自动新增对接功能。
- 用户结果导出为 ZIP，包含所选格式的数据和已有计算参数说明。片段或组分导出注明来源与选择，不把原参数说成片段重新计算的参数。通用打包下载能力同样对外部模块开放，不改变内部交换格式。

### 条件编辑

用户可以从序列、结构中的链或不连续片段建立设计模板。增删位置后，完整目标位置、序列及所选条件保持正确对应；没有原子坐标的新增位置可以保留，不虚构坐标。选中的序列或结构结果可以再次建立模板，用户无需逐位修补内部映射。逐位置、区域及位置对条件分别按其含义处理。

Protein Studio 是可独立安装的编辑模块。用户从“编辑蛋白质”节点展开工作区，通过上方三维结构和下方五条对齐轨道完成编辑；用户直接操作轨道和三维结构，不展开轨道编辑表单、嵌套操作组件或重复的三维选区操作栏。

载入结构时，用户选择链后直接进入 Studio，该链的全部蛋白质残基进入编辑轨道，无需预先指定残基范围；需要片段时在 Studio 内删除位置。文件有明确记录和对应关系的缺坐标残基保留为空坐标位置。水、金属等其他组分保留在原始文件及结构内容中，不占用蛋白质轨道位置。删除只改变当前编辑成果，原始输入完整保留。

序列、坐标、二级结构、SASA 和功能注释分别选择和维护编辑范围，各轨道可以使用不同、重叠或不连续的范围。用户可以直接编辑任一轨道中适用位置的数据；选区只指定本次操作对象，不设置可编辑边界或解锁步骤。所有轨道以实际值和空缺表达当前内容，不设置独立的固定／可变状态或控件。三维联动用于定位和预览，不覆盖其他轨道的编辑范围或数据。

局部编辑立即更新 Studio 会话，支持连续操作、撤销和重做；普通修改无需逐次预览和确认。完成时一次采用当前结果并返回原画布，保留画布视角与节点位置。取消放弃本次会话，原节点保持不变；采用失败时保留草稿供重试。项目仍按手动保存流程保存。

#### Studio 直接编辑与显示

- 点击轨道单元格定位光标，拖动或 Shift 选择范围，Ctrl/Cmd 添加不连续选区；方向键移动。序列字母替换当前值并前进，多选后输入单个字母填充全部选中位置。`+` 在光标位置之后插入一个空白位置，`-` 标记删除选中位置，再次对已删除选区按 `-` 恢复。空格清空当前轨道，保留位置。二级结构接受 DSSP8 编码，SASA 在单元格输入非负数值，功能注释在选区内直接编辑。
- 序列单字母遵循 DDBJ/NCBI 编码：常见 20 种氨基酸、U/O、B/Z/J、X，输入小写转大写。X、未填写值和删除位置分别保存。粘贴忽略排版空格与换行，按位置填写，不隐式增删位置；未支持字符使本次粘贴失败并保留原内容。粘贴中的符号不执行键盘命令。
- 修改状态按当前值与载入参照比较，并按前端视觉规范区分替换、清空、新增与删除；删除位置保留删除线。恢复原值取消修改标记，新增位置填写后仍保留新增色。替换和清空只标记对应轨道，新增和删除标记整个残基列；选区边框独立显示，不覆盖修改色。删除位置不增加解释文字。
- 删除位置及其五条轨道内容继续保留在编辑器。直接输入即恢复该位置并修改当前轨道，其他轨道恢复删除前内容。完成、保存和重开保留修改参照及删除位置；不保存跨会话逐步撤销历史。科学输出仅包含有效位置，并按有效顺序重新对应轨道和注释区间。没有有效位置时允许继续编辑，完成采用时提示至少保留一个位置。
- 三维显示使用成熟分子可视化库，默认飘带图，支持主链轨迹、棒状图、球棍图及选中残基侧链。显示方式不修改科学数据。允许根据当前坐标进行仅用于绘图的二级结构判定，不回填或输出二级结构轨道；轨道填写也不自动重建坐标。
- 三维操作以残基为最小单位，支持选择、多选、框选、整体移动和旋转；残基全部现有原子一起变换。中键旋转视角，Shift＋中键平移，滚轮缩放；G 移动、R 旋转、X/Y/Z 限轴，并提供鼠标拖动控件。变换实时预览，Enter/左键确认、Esc/右键取消。快捷键只作用于焦点所在区域；序列中的字母仍用于输入。三维操作使用坐标轨道选区，其他轨道的选区保留。
- 三维默认按主体色显示；“显示修改”默认关闭，开启后按当前轨道显示修改色，整个位置的新增、删除状态优先。选中残基临时使用选中色；已删除且有坐标的残基始终保留原形状、删除色和 100% 不透明度，选中时通过轮廓标记。显示开关不改变轨道内容、修改标记或科学输出。
- 没有坐标的位置保留全部轨道操作，坐标轨道显示空心圆；三维视图不生成假残基、占位物或补出的链段。混合选区只高亮、变换已有坐标的部分；全部无坐标时移动和旋转不可用。清空坐标后不再显示当前三维实体，可撤销恢复。

本轮测试从已确认需求重新建立。归档测试不作为行为规范，不参与当前测试发现；原始研究数据保留。归档位置和验证入口见 [Studio 验证说明](studio-validation.md)。

“编辑蛋白质”节点接收明确对象，分别交付序列、三维坐标、二级结构、SASA、功能注释，并提供同一确认成果的整体蛋白质输出。轨道携带实际值、空缺、单位及必要的位置和原子对应；编辑选区和历史留在 Studio 内部。当前序列使用单字母及空缺，保留 X、B/Z/J、U/O，不扩展任意修饰残基的化学编辑。序列输出不以完整标准序列为准入条件，实际计算要求由下游操作和工具检查。

生成节点接受整体对象或明确连接的独立轨道，两种方式互斥；独立轨道只采用已接入内容，必须具有明确一致的对象和位置对应，不按相同长度猜测。序列可接三维结构预测，三维坐标可接处理、比较和 PDB/mmCIF 导出；工具、任务和计算参数由下游选择。生成结果可以再次进入 Studio。

完成编辑将成果保存在节点上，保留输入和连线；再次打开继续编辑已确认成果，取消保留原节点。明确选择已交付的上游结果可载入编辑器；上游新结果须明确载入，旧编辑不自动重放。运行下游使用已确认成果。完整五轨成果及必要文件随项目保存、复制和跨项目采用保留，PDB/mmCIF 导出按其文件内容约定执行。

载入时自动采用上游已提供且位置对应明确的轨道内容，包括文件已有的二级结构记录；未提供的值留空，不自动计算二级结构、SASA 或功能注释，不覆盖用户编辑来补齐内容。

拖动结构立即预览，明确确认后接受，取消完整恢复。支持明确限定区域和轨道的局部采用。

随机插入的残基可继续删除、插入和编辑。确认后固定实际位置和结果，后续删除不重新抽取或补足数量；seed、数量和范围成为只读操作记录。再次随机处理基于当前内容，经预览确认后采用。普通撤销恢复前态，不通过更改历史随机步骤重算后续编辑。

清除某位置的坐标后，该位置在当前坐标轨道留空，不再重放此前变换；重新设置时按新值采用，其他位置保持原结果。原始输入文件保留供明确选择和恢复，不能自动补回已清空的值。撤销清除恢复前态。模块维护位置对应，用户无需清理内部引用。修改二级结构、SASA 或功能注释不会隐式重算三维坐标。

### 筛选、排序与集合操作

- 筛选统一为“条件＋排序＋数量上限”，top-k 不作为独立功能。每个筛选节点拥有自己的条件、评价选择、排序及数量上限设置，复制时一并复制；载体不解释或重映射全局科学筛选规则。
- 排序使用原值及用户选择的升降序，并列保持输入顺序。设置数量上限时最多取指定数量，数量不足取全部，空输入返回空集合，不因并列扩大数量。
- 评价选择不向用户暴露内部 ID。缺少必需分数或评价选择仍有歧义时停止本次操作，不隐藏候选、不任取第一条、最新值或均值。
- 筛选通过画布节点配置和执行。结果面板展示筛选成果，并允许明确采用到后续节点。
- 删除多指标加权、Pareto 及含义不清的 diversity 操作，不自动增加其他多样性功能。

## 长流程与通用性验收

主线使用真实输入：选择结构链上的部分残基，编辑长度及条件，生成多个候选，按需要预测结构、追加评价并与用户上传或流程生成的明确参考比较，再按所选指标、阈值、排序和数量上限筛选。选中结果作为下一轮模板，每模板再次生成多个候选，重复用户指定轮数。

每次演习在执行前确定输入、参数和可检查结果。具体候选数量、轮数、工具、指标和阈值属于测试实例。验收核对真实数据与条件的传递、结果对应、评价归属和各轮输入；根据实际分数独立计算应选名单，并与筛选输出核对。

每项关键接口还须通过主线外的组合验证：独立上传对象直接评价；单独编辑、分析或筛选；在适用范围内替换工具；改变顺序、分支与参考；逐模板筛选和合并后筛选；中间结果跨项目采用后由独立模块继续计算；外部模块使用自定义格式交接、执行和保存。工具接入同时验证同一操作使用两个实际工具，以及同一工具服务两个不同操作。

验收记录用户操作、实际经过的公开入口、输入输出及可观察结果。科学计算路径使用真实工具调用，接口与状态测试分别记录。人工构造的异常状态只用于必要的接口检查，不能据此扩张产品职责。
