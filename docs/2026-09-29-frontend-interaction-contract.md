# 前端操作约定

本文件描述当前前端操作行为。2026-09-29 用户手动测试后阶段性通过；结构变换的实时预览仍是明确的后续改进项。

## 画布

搜索打开即聚焦，↑↓定位，Enter 添加，Escape 关闭。空白右键的落点决定新增位置；输出端口拖至空白后只显示可连接的节点，添加与连线共同成为一次编辑。取消重连保留原连线。

多选工具条显示数量与组合、复制、删除。组支持命名、嵌套、独立复制和解组；解组只提升直接成员。组的公开端口映射精确原始节点与端口，不按名称合并，不改变多来源顺序。组是画布组织，实际计算节点和连线保持现有表示。

Tab 进入组；组内 Tab／Ctrl+Tab 或面包屑返回。文本输入中 Tab 保持字段导航。每层保存自己的视图，进入返回不进入内容撤销历史。组的布局更新不得覆盖不可见成员的位置。

参数组分别展开；Enter 接受输入，Escape 恢复原值。折叠后不可连接的端口解释原因并提供展开入口。

## 矩阵

结构视口与一张矩阵组成可调整工作区。窄桌面可切换结构／矩阵。常用操作位于矩阵附近，随机、合并和详情按需展开。

五条轨道为行，残基为列，固定轨道标题。单击选择，键入替换，F2／双击编辑现值；Enter 确认后向下一轨道，Tab 向下一残基，Shift 反向。Escape 取消当前输入。活动格、选区和编辑态分别显示。

Shift 从固定锚点扩展；Ctrl／⌘ 追加或移除。工具条显示轨道与残基范围和数量。Sequence、SS8、SASA 原位编辑；Coordinates 进入结构操作；Function 在局部编辑区修改完整区间，一次输入编辑一个对象。

复制按显示顺序。粘贴从活动格开始；多选单值可批量应用，多值需匹配目标维度，非连续选区按残基轴顺序映射。无效类型或尺寸拒绝整个操作并就地解释，不做部分写入。剪贴板快捷键不能触发字母编辑。

单格确认、批量应用、完整变换各是一条编辑历史。输入缓冲与异步预览分离，等待时保留完整键入；只接受最新有效预览。失败保留输入和选区。清除选择不取消内容，取消内容不移动镜头或工作位置。顶部保存整份编辑。

## 结构视口

中键旋转视角，Shift＋中键平移，滚轮缩放。悬停显示残基身份；点击选择并显露矩阵对应位置；聚焦是独立动作。悬停不抢焦点或滚动矩阵。

选择工具区分替换、增加、移除；Shift 点选切换追加。B 进入穿透框选并显示残基标记，释放完成，Escape 取消。标记优先取 CA，否则取现有原子的几何中心。本轮无“仅可见框选”开关。

G 开始沿视平面移动，R 绕视线旋转，方向取操作开始时镜头。X/Y/Z 切换世界轴，再按同轴解除。数字输入后轴键仍可用。自由移动数字沿已有鼠标方向，没有方向时提示移动鼠标或选轴；约束轴接近视线时只接受明确数值并解释原因。

Enter／左键确认，Escape／右键取消。等待有效预览可见，取消立即撤回。更新、确认、取消和撤销保留镜头；只有初次载入、显示全部、聚焦选区主动适配视图。

## 结果与公共控件

候选列表与详情／比较相邻，详情不放在长列表底部。已选清单可查看、逐项移除和清空。比较独立于导出勾选，最多四项，可替换。

Workflow／Results 往返保留当前项目与 Run 的筛选、滚动、勾选和比较，运行状态和控制两边可达。弹窗与菜单采用 Radix 的键盘和焦点行为，关闭返回原入口。画布、矩阵、文本、三维持续操作、弹窗分别处理快捷键；撤销与重做展示动作名称。

## 复用边界

React Flow 管理画布事件与端口；AG Grid Community 36.2.0 提供编辑器、焦点和虚拟滚动，残基选区与浏览器剪贴板为前端适配，不使用 Enterprise。3Dmol 公共接口承担渲染、投影、拾取和镜头，关闭默认鼠标处理后统一操作语义，不修改依赖源码。Radix Dialog、Dropdown Menu、Context Menu 提供公共弹窗和菜单。

## 当前限制：结构变换预览

当前直接使用 3Dmol.js，并非 Python 包装层 py3Dmol。G/R 输入经 90ms 尾沿防抖调用后端预览，返回后清除旧模型、重新载入 PDB 并恢复镜头。连续鼠标输入会推迟请求；因此当前是异步预览，尚不能宣称逐帧实时反馈。这是已确认的体验问题，不影响本次阶段性接受。

后续应优先评估浏览器内的临时坐标预览：以操作开始时的坐标为基准，在动画帧中显示当前变换，取消恢复起点，确认后同步后端验证结果，并保留一次变换一次历史的行为。需测量坐标更新和渲染耗时，避免每次鼠标移动都经过网络及完整模型重建。该方案尚未实施；不承诺未经测量的帧率，也不改变后端科学契约。

PyMOL 不是当前网页组件的直接替换。更换渲染器本身不会消除上述防抖及服务端往返，应先验证 3Dmol 公共接口下的局部预览能力，再根据实测瓶颈决定是否替换。
