# 前端视觉规范

应用于载体、节点画布、模块管理、结果查看和 Protein Studio。以中性浅色界面承载彩色的科学内容与操作状态。

## 载体与画布

采用方案 A 的画布与侧栏布局：单层项目顶栏，画布占据剩余空间，结果面板并列在右侧。项目名只出现一次。节点使用紧凑标题、端口和控件；文件名、计算状态与分数保留，常驻说明和内部编号移除。详情按需展开，节点参数展开不移动其他节点。


| 用途 | 色值 |
| --- | --- |
| 面板、节点、轨道底色 | `#FFFFFF` |
| 画布 | `#F3F4F6` |
| 控件、辅助区 | `#F8F9FB` |
| 主文字 / 次文字 | `#20242C` / `#626B79` |
| 分隔边界 | `#D9DEE7` |
| 主要操作、选中、键盘焦点 | `#345BDB` |
| 选中背景 | `#EDF2FF` |

端口和连接线共享同一格式颜色，节点底板保持中性。主要操作用实色蓝；普通按钮用白底与边框。浮层通过边界和轻阴影区分，不遮暗整个工作区；模态窗口使用半透明遮罩。错误使用浅红底和深红文字。

## Protein Studio

| 状态 | 三维颜色 | 轨道背景 |
| --- | --- | --- |
| 默认主体 | 浅天蓝 `#94CFF0` | 白色 |
| 选中残基 | 紫罗兰 `#AB8BE8`，轮廓 `#8058C4` | 保留修改背景，以蓝色边界定位 |
| 替换 | 奶油黄 `#F5CC80` | `#FFF0CE` |
| 清空 | 珍珠灰 `#CED2D8` | `#ECEEF1` |
| 新增 | 浅薄荷绿 `#99D8B0` | `#E2F3E8` |
| 删除 | 浅珊瑚红 `#F1A0A8` | `#FCE6E8`，保留删除线 |

三维颜色显示与编辑状态的交互规则见[需求](requirements.md#studio-直接编辑与显示)。轨道、图例与三维使用同一色系。三维背景为 `#FAFBFC`，飘带暗面保留柔和的同色明暗，避免大块黑灰阴影。

## 反馈与适用范围

沿用 120 ms 的悬停与焦点过渡，遵守系统的减少动态效果设置。显示颜色不修改科学数据。

载体样式在 `webui/src/host.css`；Studio 独立样式与颜色在 `modules/sequence_edit/ui/`。Studio 使用自有样式变量，可在其他载体中保持一致外观。三维补光由模块打包流程应用，不修改 `repositories/` 或已安装依赖的源文件。
