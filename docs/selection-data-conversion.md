# 筛选配置的数据转换

产品要求以[当前有效决策](documentation-governance-decisions.md)为准。转换程序只处理保存资料，不执行旧算法，也不重新计算科学结果。

在停止原安装的运行准入、确认所有 Run 已结束后，将原数据根转换到一个尚不存在的新目录：

```sh
python -m modules.selection.migrate /absolute/source-data /absolute/converted-data
```

该命令复制整个数据根，检查全部保存输入与已发布成果可读取，再发布新目录。它不修改来源目录，不改变 `PROTEIN_WORKBENCH_DATA_ROOT`，不启动或停止服务。失败或中断时不发布新目录；原安装和原件仍保留。活动根的最终核对及切换由部署操作完成。

## 保存资料与当前读取

原 Commit、Run transactions、输入、结果对象及身份保留原字节。已结束 Run 的 `reading.json` 从实际记录的通用事实形成，不解释旧筛选规则或重放旧 reducer；原状态、失败原因、发布成果、来源和事件游标保持。历史 Commit 的参数导出继续读取原始记录。

随包教学结果 ZIP 采用相同的统一读取资料。原归档条目（包括原 manifest、Commit、Ledger 和科学载荷）保持原字节；新增 `readings.json` 索引、Run 读取及当前 Draft 资料。安装直接读取这些资料，导出使用原 Commit 快照，不将原计算重新编译为当前规则。

`draft-readings` 是当前应用保存与打开 Draft 的唯一表示。转换为每个原 Draft 准备当前读取资料，使原命名版本、工作区编号及返回点仍可打开；改变配置时追加新的当前 Draft 和工作区头。旧 `drafts` 仅保留原件，不作为运行时读取失败的备用路径。新保存与项目复制使用当前表示。

不能等价转换的节点保留原节点身份、参数、Binding 和连线，并附带通用 `preserved_configuration`。界面显示不可运行原因与原设置，不加载当前模块参数默认值或专用编辑器。原 Commit 同样记录明确的执行阻止原因；按原 Commit ID 发起计算也不能绕过。查看、导出、采用原结果仍可进行。需要使用新操作时，由用户新建相应节点并明确配置。

## 等价范围

| 原配置 | 转换结论与依据 |
|---|---|
| 已采用新节点本地参数的操作 | 保持原配置，不重新解释。 |
| Manual | 完整 Candidate 引用匹配、缺失时报错及输入相对顺序一致，保持原配置。 |
| Utility 排序、加权 | 旧操作按 Candidate ID 破同分，当前操作保留输入顺序；单次结果未出现同分不能证明以后等价。旧转换存在也不代表当前已批准其加权含义。保留为不可运行。 |
| Top-k | 除同分差异外，旧操作会拒绝数量不足，而当前最多取 k 个并允许空输入。保留为不可运行。 |
| Pareto | 旧操作使用 Utility 并按内部 ID 排列输出，当前使用原值与所选方向并保留输入顺序。保留为不可运行。 |
| Filter | 旧实现先按 Candidate ID 分组后检查内容，当前按完整引用匹配；同 ID 不同内容的观察会导致不同结果。未证明来源约束足以排除此差异，且旧默认范围外观察政策不同，故保留为不可运行。 |
| Diversity | 本轮已移除，保留原设置及连线，不替换算法。 |

未被节点引用的旧全局设置保存在一个普通的不可运行保全节点中。该节点没有注册的执行实现，不是旧接口别名。转换不会从摘要推断参考对象或区域，也不会改写历史 Score Context。

结构比较新增的可读区域信息属于 Binding 的输出行为；原 TM-score 与 RMSD 的数值 Method 保持原定义。该输出行为参与执行身份，原分数仍可采用，既有缓存不会冒充带有新区域投影的计算。
