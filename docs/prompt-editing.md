# Prompt 编辑与区域采用

本文件维护序列与设计条件编辑模块的当前要求、有效数据操作和实现差距。依据是[当前有效决策](documentation-governance-decisions.md)，问题状态见[治理问题清单](2026-10-15-documentation-governance-issues.md)。载体提供通用编辑与保存能力，Prompt 及其工具条件解释属于功能模块。

## 编辑对象与会话

当前普通 `prompt_authoring.author` 节点的 `document` 表达编辑意图；[recipe](../modules/prompt_authoring/recipe.py)是预览与执行共用的解释 owner。浏览器组装用户意图，随机选择和实际数据处理由模块完成，不能在浏览器重做随机算法或按显示位置猜残基对应。

空白来源默认布局模式，其他来源默认条件模式。桌面工作区为可调宽度的结构视口与残基矩阵，窄屏用页签切换。残基为列，Sequence、Coordinates、SS8、SASA、Function 五条轨道为行。常用选择、指定值和清除在矩阵附近；插入/删除、批量、随机、Function、变换、合并和详情按需打开。

矩阵单击选择，键入替换，F2/双击编辑现值，Enter 接受并进入下一轨道，Tab 进入下一残基，Shift 反向，Escape 取消输入。Shift 连选保留最初锚点，Ctrl/⌘ 追加或移除。Sequence、SS8、SASA 原位输入；坐标与 Function 使用专用控件。混合值和 Mask 不显示成猜测的默认值；非法输入留在编辑器，输入法组合确认不提前提交。

复制按残基列序及可见轨道顺序生成 TSV。粘贴先检查整个目标范围，类型或尺寸错误时整次拒绝；原生输入框内的剪贴板只修改文本。单格确认、有效粘贴、批量操作和完整 G/R 各自是一条可撤销编辑。快速输入保留顺序、输入与选区；撤销/重做按当前上下文恢复内容和位置，不重抽随机值。三维选择可定位矩阵但保留三维键盘焦点，清除选择不取消编辑。

轨道摘要区分 whole-track absent、present/all-Mask 与实际值。Function 编辑完整 `(label, start_residue_id, end_residue_id)`；拆分产生 `[start, split]` 与 `[next, end]`。同链连续区间由模块解释，允许重叠、拒绝完全重复；删除或合并不能静默截短或扩展 annotation。

## 随机操作

随机 Mask/插入控件表达 seed、数量和明确适用范围，展示模块实际产生的位置。采用后实际结果固定为普通布局与轨道编辑；删除不重抽、不补足。已采用的 seed、数量、范围和实际位置为只读记录，不能修改或移除旧步骤重算。再次随机基于当前内容发起新操作，预览后确认；不由前端猜随机结果。

随机插入残基与其他残基一样可删除、继续插入和编辑，也可作为普通编辑锚点。模块负责保持来源与编辑结果正确，不要求用户理解生成 ID 或固化内部状态。当前前端与 recipe 布局已支持这些后续编辑；随机生成结果和后续编辑之间的身份对应仍由模块维护。

## 结构操作

使用世界坐标和列向量 `x' = R (x − origin) + origin + translation`，距离 Å、界面角度 °、右手旋转。G 默认在操作开始时的视平面移动，R 默认绕当时视线旋转；X/Y/Z 切换世界轴约束，同轴再按解除。鼠标、数字和轴键属于一个持续操作，自由移动的数值沿已有鼠标方向；无方向时提示先移动或选轴。轴接近视线而不能可靠求鼠标位移时仍保留数值输入。

旋转默认中心是所选残基全部现有原子的坐标算术平均，不按残基平均或只取 CA。可选择一个残基的现有 named atom（有 CA 时将其作为默认候选），或输入世界坐标中心；显示标记与提交 `origin` 一致。允许不连续选区，每个参与残基须有坐标；Mask 不伪造坐标。未选残基保持不变，镜头导航不改 document。

中键旋转镜头，Shift+中键平移，滚轮缩放。初载、显示全部、主动聚焦时才重新适配视图。B 使用穿透框选，标记优先取现有 CA，否则取现有原子几何中心；选择标记与全原子变换中心不同。支持点选及替换/增加/移除选区，尚未提供只选可见残基的框选模式。

拖动时立即显示临时坐标，Enter/左键确认后采用，Escape/右键取消恢复全部起点。当前 [StructureViewer](../webui/src/StructureViewer.tsx)以 requestAnimationFrame 更新本地临时显示，确认时将最终矩阵、origin、translation 和 residue IDs 交后端预览；等待确认期间可取消，迟到响应不能接纳已取消操作。预览/确认/撤销保留镜头和裁剪。当前使用 3Dmol.js；未测量的结构规模不作帧率承诺。

同链相邻的选中/未选中残基形成变换边界，展示实际位置并提醒可能改变几何；不猜键长阈值、不自动移动邻居或最小化。这是操作提示，不是附加的科学准入体系。

## 局部采用与对应

来源与目标分别展示链、残基范围和轨道，用户能明确采用局部区域及轨道。选择实际位置与维护内部身份分别处理：用户可明确对应哪段数据，模块负责内部 identity 和映射，不要求填写内部 ID。

当前来源合并以有序 `merge_sources` 和 `source_merges` 表达；每项包含 `source_index`、`correspondence`、`track_adoptions`、`adopt_annotations`、`remove_annotations`。这些是模块内部 document 数据，不是要求未来用户手写的输入表。

- 对应表按来源与目标各自顺序完整表达每个位置。`match` 消费一对位置，`source_gap` 只消费来源，`target_gap` 只消费目标，`insert` 创建新目标位置。唯一内部身份由模块负责生成和维护，不能按数组下标猜真实对应。
- 采用细到来源残基×轨道。现有 `mask_policy` 明确表达保留目标旧值或采用来源 Mask 清除目标；whole-track absent 不冒充 Mask。每项采用必须有有效对应，不暗中改变未选择区域。
- annotation 按完整 tuple 采用/移除；来源区间只有完整、连续、同链映射时才能采用，不截短让它勉强成功。显式移除在布局扩展前发生，未采用/移除的目标 tuple 保留，完全重复仍由现有 owner 处理。
- 当前新位置先为 Mask，仅填入明确采用的轨道。预览展示新增位置、轨道、Mask 处理和完整 annotation 后果。多来源按 document 顺序处理，后项读取前项结果；这些事实不增加未确认的全平台默认清空或保留策略。

当前合并编辑提供手动对应、gaps 和分屏，并不自动对齐；这条现有实现事实不能被扩大成禁止结构比较模块使用自动对应。来源与目标可以独立选择，已有明确 Match 可同步高亮。新增位置由用户选择目标链与对应行位置，模块生成内部身份。表格和分屏均不要求填写内部 ID；打开已保存文档不改写其身份。

## Recipe 与预览的当前约定

当前解释顺序是主来源/空白 chains、显式 target layout、按顺序随机插入、source merges、普通 track edits、依次 rigid transforms、随机 Mask、最终完整 Function tuples。每个变换读取前一个变换结果；合并建立编辑基线，后续显式编辑作用于该基线。打开与预览先按此顺序求值，再将实际随机结果及变换后的坐标固化为普通编辑，保留随机参数只读记录。旧文档按原顺序恢复实际结果，打开不自动保存。清除坐标后旧变换不再执行，重新设置坐标采用新值；撤销恢复之前的文档与实际坐标。

`merge_targets[i]` 是第 i 次合并前的目标，最后一项是全部合并后、普通轨道/坐标/随机 Mask/最终 Function 覆盖前的值；没有合并时也有初始目标。对应表与 annotation 移除引用该阶段，不能引用本次合并自己的输出。无效预览没有有效阶段值；若保留上一次预览，明确说明它不是当前输入的结果。

采用合并新增位置后，模块将其物化为普通插入目标，并保留来源对应为 Match；其余位置补 Target gap，实际轨道与完整注释保持不变。后续随机插入针对当前完整布局，新增位置同步进入既有对应的 Target gap。合并新增位置不会伪装成原主来源。删除目标位置时同步已有对应和采用引用，其他映射保留；无法继续完整表达的 annotation 由用户明确处理，不自动裁剪。普通插入按明确锚点在各阶段建立适当 gap，不凭插入创造来源 Match。初始来源或明确空白声明决定可用目标链范围；允许原链位置全部替换，不凭来源 chain 暗中新增目标链，也不在最终值保留幽灵残基。

保留非空 `source_merges` 的节点，其现有有序来源目前要求成为新来源列表的完整前缀。画布可无操作重连或末尾追加；替换、删除、移动、重排需要先在编辑器明确调整合并内容。拒绝时保留整份流程并定位节点；同时删除目标节点时不保护已删除配置，但仍检查其他保留节点。该边界不建立上游变化追踪系统，也不让载体解释残基含义。

## 接受编辑与持久保存

open/preview 可携带完整 prospective Workflow，包含会话拟添加的来源节点、边及目标 document。预览只解析，不写 Draft；关闭或取消不留下半份图。新增来源保持编辑器实例和尚未确认内容，来源选择取消回到原会话。已上传但未引用的不可变 Input 按[输入生命周期](workspace.md#项目生命周期复制与输入)保留。

确认采用时，图与 document 是一个完整编辑；项目持久化仍由用户手动触发。手动保存复用已确认 normalized document，只有内容、来源或版本变化才重新预览；不得因保存而再次运行 recipe、抽随机值或生成/比较哈希。打开编辑时的 Draft revision 在持久化边界比较一次，冲突保留内容，不自动合并或重试；其他未完成节点不因保存被强制编译。

命名版本保存以该版本为内容基线，保留打开前返回点，并在手动保存时一次发布完整 Draft/UI。长会话布局操作作用于最新 desired UI。确认只采用本地编辑，显式项目保存才发布完整流程与布局。

## 工具条件与模块职责

当前条件视图展示 ESM3 的有效 sequence Mask、SS8/SASA absent/present、Function 区间及 atom37 投影，同时列出未进入该工具的 named atoms。工具不支持的科学内容保留在原 Prompt，兼容性原因只针对该工具的调用；模型安装、服务可达和实际运行准备是另一个问题。

Prompt Studio 通过统一 React 模块接口加载，工具条件来自已启用模块的 `value_previews` 声明。ESM3 模块调用自己的 Adapter/Operation，公共 codec 只编码 `tool_projections`，界面保留模块给出的完整有效输入与兼容性说明。禁用 ESM3 不限制一般 Prompt 编辑。[架构](architecture.md)及[模块能力](module-capabilities.md)维护相应职责。

## 核对范围

新行为测试覆盖模块发现、禁用工具后编辑、预览采用后保存重开及受控 SDK 传参；浏览器覆盖编辑保存、随机插入后改值与删除、取消、结构临时移动取消、局部采用和重开。受控 SDK 不等于线上 Provider 验收，也不宣称测量过交互性能。
