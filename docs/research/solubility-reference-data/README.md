# 可溶性原始参考资料

SoluProt FASTA 与 full CSV 来自项目维护移植包 `soluprot 1.1.0` 的 `data/test.fa`、`data/test.csv` 首例。no-TM CSV 为相同输入在独立无 TMHMM 特征模型上的结果。来源见 [SoluProt-next](../../../repositories/soluprot-next/README.md)。

Protein-Sol FASTA 和 CSV 保留 October 2017 官方下载包中的两个结果。来源为 [官方归档入口](https://protein-sol.manchester.ac.uk/cgi-bin/utilities/download_sequence_code.php)
